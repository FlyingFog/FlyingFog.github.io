# FlyingFog Github Page

Here is the [Homepage](https://FlyingFog.github.io).


I have reconstructed the homepage, since there are many new things to share.

## Homepage front matter

Set `mottos` in `content/_index.md` (and `content/_index.zh.md`) as a YAML list. The homepage displays one at random; clicking it selects another.

```yaml
mottos:
  - First motto.
  - Second motto.
```
